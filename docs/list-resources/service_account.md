# activedirectory_service_account (List Resource)

Discovers service accounts for GUID import. The SDK materializes a bounded query; this is not an unbounded LDAP page stream.

```terraform
terraform {
  required_version = ">= 1.14.0"
  required_providers {
    activedirectory = { source = "deploymenttheory/activedirectory" }
  }
}

# Supply AD_HOST, AD_USERNAME, AD_PASSWORD and, for a private CA, AD_CA_CERT_PEM
# through your secret manager or process environment. Hostname/chain checks remain enabled.
provider "activedirectory" {
  auth_method = "simple"
  transport   = "ldaps"
}
```

```terraform
list "activedirectory_service_account" "automation" {
  provider = activedirectory
  config {
    base_dn = "OU=Service Accounts,DC=example,DC=test"
  }
}
```

```terraform
list "activedirectory_service_account" "group_managed" {
  provider         = activedirectory
  include_resource = true
  limit            = 100
  config {
    base_dn      = "OU=Service Accounts,DC=example,DC=test"
    ldap_filter  = "(objectClass=msDS-GroupManagedServiceAccount)"
    scope        = "one_level"
    page_size    = 100
    result_limit = 100
  }
}
```

The SDK intersects the raw filter with its sMSA/gMSA class filter and excludes ordinary dMSAs.
An explicit base DN and finite query bounds are required. The query starts when the consumer
iterates, sorts usable rows by GUID, and stops on cancellation or consumer exit. Terraform's
`limit` can lower the configured SDK bound; reaching it does not prove search exhaustion.
Partial failures preserve usable identities alongside diagnostics.

Identity is exactly `{ id = objectGUID }`. Snapshots use the actual service-account resource
schema, preserve unavailable optional observations as null, and require visible GUID/name
and canonical sAMAccountName. They never include a password or raw security descriptor.
Password-version metadata starts at zero and undiscoverable outbound creation intent starts
at false, matching GUID import. Generating a configuration does not install an account,
retrieve a managed password or authorize mutation of the discovered object.

## Schema

### Required

- `base_dn` (String) Explicit search-base distinguished name.

### Optional

- `ldap_filter` (String) Raw LDAP filter intersected with the SDK's sMSA/gMSA class filter.
- `page_size` (Number) LDAP page size from 1 to 1000; defaults to 256.
- `result_limit` (Number) Maximum materialized objects from 1 to 10000; defaults to 1000. Terraform's limit can lower this bound.
- `scope` (String) base, one_level or subtree; defaults to subtree.
