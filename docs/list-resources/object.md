# activedirectory_object (List Resource)

Discovers objects for GUID import. The SDK materializes a bounded query; this is not an unbounded LDAP page stream.

```terraform
terraform {
  required_version = ">= 1.14.0"
  required_providers {
    activedirectory = { source = "deploymenttheory/activedirectory" }
  }
}

# Supply AD_HOST, AD_USERNAME, AD_PASSWORD and, for a private CA, AD_CA_CERT_PEM
# through your secret manager or process environment. Hostname/chain checks remain enabled.
provider "activedirectory" {
  auth_method = "simple"
  transport   = "ldaps"
}
```

```terraform
list "activedirectory_object" "example" {
  provider = activedirectory
  config {
    base_dn     = "OU=Contacts,DC=example,DC=test"
    ldap_filter = "(objectClass=contact)"
  }
}
```

```terraform
list "activedirectory_object" "contacts" {
  provider         = activedirectory
  include_resource = true
  limit            = 100
  config {
    base_dn      = "OU=Contacts,DC=example,DC=test"
    ldap_filter  = "(objectClass=contact)"
    scope        = "one_level"
    page_size    = 50
    result_limit = 500
    properties   = ["description", "jpegPhoto"]
  }
}
```

No object class is inferred. The SDK materializes one bounded search, then the provider
sorts by GUID and respects cancellation/consumer stop. Terraform's `limit` can lower the
configured materialization bound. Partial rows precede failure diagnostics; duplicate GUIDs
never become duplicate import identities. Reaching a bound does not prove search exhaustion.

`properties` selects raw read-only observations. Snapshots use the actual managed resource
schema and its GUID identity; the instantiated class must be visible for a resource snapshot.
Generated resources leave raw ownership unset. Add explicit attribute/value ownership only
after review, or use the managed resource's selected-attribute JSON import form.

## Schema

### Required

- `base_dn` (String) Explicit search-base distinguished name.

### Optional

- `ldap_filter` (String) Explicit raw LDAP filter; no object class is inferred.
- `page_size` (Number) LDAP page size from 1 to 1000; defaults to 256.
- `properties` (List of String) Explicit raw LDAP display names to observe without taking raw attribute ownership in generated resources.
- `result_limit` (Number) Maximum materialized objects from 1 to 10000; defaults to 1000. Terraform's limit can lower this bound.
- `scope` (String) base, one_level or subtree; defaults to subtree.
