# activedirectory_group_member (List Resource)

Discover direct group-member links for composite-ID import. Primary and nested memberships are excluded.

```terraform
terraform {
  required_version = ">= 1.14.0"
  required_providers {
    activedirectory = { source = "deploymenttheory/activedirectory" }
  }
}

# Supply AD_HOST, AD_USERNAME, AD_PASSWORD and, for a private CA, AD_CA_CERT_PEM
# through your secret manager or process environment. Hostname/chain checks remain enabled.
provider "activedirectory" {
  auth_method = "simple"
  transport   = "ldaps"
}
```

```terraform
list "activedirectory_group_member" "example" {
  provider = activedirectory
  config {
    group_guid = "11111111-1111-4111-8111-111111111111"
  }
}
```

```terraform
list "activedirectory_group_member" "importable" {
  provider         = activedirectory
  include_resource = true
  limit            = 10000
  config {
    group_guid   = "11111111-1111-4111-8111-111111111111"
    result_limit = 10000
  }
}
```

GUIDs identify directory objects; names and DNs may change without changing the
ordered relationship identity. Primary-group and nested/effective membership are
excluded. Foreign security principal resolution is not performed.

When no member attribute is returned, actual emptiness and denied visibility are
indistinguishable. Discovery reports a visibility warning; the collection data
source keeps `complete = false`. Zero returned rows do not establish that no
links exist. A fully returned visible collection can report completion.

The SDK materializes a bounded group query and resolves each returned member to a
local GUID. Rows sort by member GUID. An omitted attribute alone never establishes
an empty group. A failed or truncated query retains usable rows and reports the
incomplete result. A bound does not prove that further links exist.
