# activedirectory_group (List Resource)

Discovers groups for GUID import. The SDK materializes a bounded query; this is not an unbounded LDAP page stream.

```terraform
terraform {
  required_version = ">= 1.14.0"
  required_providers {
    activedirectory = { source = "deploymenttheory/activedirectory" }
  }
}

# Supply AD_HOST, AD_USERNAME, AD_PASSWORD and, for a private CA, AD_CA_CERT_PEM
# through your secret manager or process environment. Hostname/chain checks remain enabled.
provider "activedirectory" {
  auth_method = "simple"
  transport   = "ldaps"
}
```

```terraform
list "activedirectory_group" "example" {
  provider = activedirectory
  limit    = 100
  config {
    base_dn = "OU=Groups,DC=example,DC=test"
  }
}
```

```terraform
list "activedirectory_group" "application" {
  provider         = activedirectory
  include_resource = true
  limit            = 500
  config {
    base_dn      = "OU=Groups,DC=example,DC=test"
    ldap_filter  = "(name=Application*)"
    scope        = "subtree"
    page_size    = 100
    result_limit = 500
  }
}
```

Keep provider configuration in `providers.tf` beside the query file. The SDK materializes a
bounded query when iteration starts. Rows sort by GUID, and emission honors cancellation and
consumer stop. This is not an unbounded LDAP page stream. Terraform's `limit` can lower the
configured bound. Reaching a bound does not prove the full search was exhausted; failures
retain usable identities without claiming completion.

Identity is exactly `{ id = objectGUID }`. Resource snapshots contain typed observations and
no member collections or writable raw flag mask. Unavailable account name, category or scope
prevents an import snapshot from being emitted. The query's search scope is independent of
the observed group scope in the resource snapshot. Configuration generation authorizes no
conversion, rename, move or membership change.
