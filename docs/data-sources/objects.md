# activedirectory_objects (Data Source)

Reads objects below an explicit search base. Results are bounded, sorted by GUID and report completeness separately.

```terraform
terraform {
  required_version = ">= 1.14.0"
  required_providers {
    activedirectory = { source = "deploymenttheory/activedirectory" }
  }
}

# Supply AD_HOST, AD_USERNAME, AD_PASSWORD and, for a private CA, AD_CA_CERT_PEM
# through your secret manager or process environment. Hostname/chain checks remain enabled.
provider "activedirectory" {
  auth_method = "simple"
  transport   = "ldaps"
}
```

```terraform
data "activedirectory_objects" "example" {
  base_dn = "OU=Contacts,DC=example,DC=test"
}
```

```terraform
data "activedirectory_objects" "contacts" {
  base_dn      = "OU=Contacts,DC=example,DC=test"
  ldap_filter  = "(objectClass=contact)"
  scope        = "one_level"
  page_size    = 100
  result_limit = 500
  properties   = ["description", "jpegPhoto", "telephoneNumber"]
}
```

No object class is inferred: supply a raw LDAP filter to select the classes you need.
Results sort by GUID. `complete` and `limit_reached` distinguish search exhaustion from
bounded materialization; partial observations remain alongside diagnostics. Zero never
makes a query unbounded. This data source owns no objects or attributes.

Select raw LDAP display names explicitly through `properties`. `observed_attributes`
retains their bytes as padded base64 sets, including zero-length values. `attribute_status`
distinguishes present, absent, unloaded and partial attributes. Absent may mean hidden by
access controls; it does not prove the attribute is unset. `attribute_ranges` retains
incomplete returned ranges separately instead of presenting them as complete value sets.
Base64 preserves binary values; it does not encrypt Terraform state.

The `object_classes` list preserves the AD DS class hierarchy order. Its last value is the
instantiated class, exposed separately as `object_class`; see the [Microsoft AD DS specification](https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-adts/1de0b9e3-6cc6-4a8c-b9da-715dc301645b).

## Schema

### Required

- `base_dn` (String) Explicit distinguished name of the search base.

### Optional

- `ldap_filter` (String) Explicit raw LDAP filter; no object class is inferred. PowerShell expressions are not parsed.
- `page_size` (Number) LDAP page size from 1 to 1000; defaults to 256.
- `properties` (Set of String) Explicit raw LDAP display names to observe as base64 sets; identity fields are always selected.
- `result_limit` (Number) Maximum materialized objects from 1 to 10000; defaults to 1000. Zero never enables an unbounded query.
- `scope` (String) base, one_level or subtree; defaults to subtree.

### Read-Only

- `complete` (Boolean) Whether the SDK completed the entire selected search.
- `id` (String) Deterministic query fingerprint; individual objects retain their GUID identities.
- `limit_reached` (Boolean) Whether the configured bound stopped retrieval; it does not prove further matches exist.
- `objects` (Attributes List) Usable object observations sorted by GUID. (see [below for nested schema](#nestedatt--objects))

### Nested Schema for `objects`

Read-Only:

- `attribute_ranges` (Map of Set of String) Raw returned range descriptions and base64 sets. These are incomplete ranges, never a complete attribute value set.
- `attribute_status` (Map of String) Retrieval status for each selected raw attribute: present, absent, unloaded or partial. Absent can mean access-hidden.
- `distinguished_name` (String) Directory-observed distinguished_name.
- `id` (String) Directory-observed id.
- `name` (String) Directory-observed name.
- `object_class` (String) Directory-observed object_class.
- `object_classes` (List of String) Ordered AD DS objectClass sequence; the instantiated class is last.
- `observed_attributes` (Map of Set of String) Explicitly selected raw attributes as canonical padded base64 sets. Unavailable values remain null; omission does not prove an attribute is unset.
- `parent_dn` (String) Directory-observed parent_dn.
