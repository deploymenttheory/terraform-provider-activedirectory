# activedirectory_group (Data Source)

Reads one group by GUID or DN. Missing or inaccessible objects report a diagnostic; no directory state is managed.

```terraform
terraform {
  required_version = ">= 1.14.0"
  required_providers {
    activedirectory = { source = "deploymenttheory/activedirectory" }
  }
}

# Supply AD_HOST, AD_USERNAME, AD_PASSWORD and, for a private CA, AD_CA_CERT_PEM
# through your secret manager or process environment. Hostname/chain checks remain enabled.
provider "activedirectory" {
  auth_method = "simple"
  transport   = "ldaps"
}
```

```terraform
data "activedirectory_group" "example" {
  object_guid = "b836f3d7-6ab2-45f4-a4db-67827ee3be44"
}
```

```terraform
data "activedirectory_group" "by_dn" {
  dn = "CN=Application Readers,OU=Groups,DC=example,DC=test"
}
```

Supply exactly one known `object_guid` or `dn`. Hidden or unavailable properties remain null;
category and group scope are not guessed. Missing, denied or incomplete observations return
diagnostics. This data source owns no group attributes or membership.
