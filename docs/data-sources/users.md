# activedirectory_users (Data Source)

Reads users below an explicit search base. Results are bounded, sorted by GUID and report completeness separately.

```terraform
terraform {
  required_version = ">= 1.14.0"
  required_providers {
    activedirectory = { source = "deploymenttheory/activedirectory" }
  }
}

# Supply AD_HOST, AD_USERNAME, AD_PASSWORD and, for a private CA, AD_CA_CERT_PEM
# through your secret manager or process environment. Hostname/chain checks remain enabled.
provider "activedirectory" {
  auth_method = "simple"
  transport   = "ldaps"
}
```

```terraform
data "activedirectory_users" "automation" {
  base_dn = "OU=Automation,DC=example,DC=test"
}
```

```terraform
data "activedirectory_users" "engineering" {
  base_dn      = "DC=example,DC=test"
  ldap_filter  = "(department=Engineering)"
  scope        = "subtree"
  page_size    = 256
  result_limit = 1000
}
```

The SDK intersects the raw LDAP filter with its user/inetOrgPerson filter and excludes computer
subclasses. An explicit base DN and finite bounds are required. Results sort by GUID; `complete`
and `limit_reached` distinguish exhaustion from bounded materialization. Usable partial rows are
retained alongside errors. No PowerShell filter grammar or unbounded zero limit is accepted.

## Schema

### Required

- `base_dn` (String) Explicit distinguished name of the search base.

### Optional

- `ldap_filter` (String) Raw LDAP filter intersected with the SDK's user class filter. PowerShell expressions are not parsed.
- `page_size` (Number) LDAP page size from 1 to 1000; defaults to 256.
- `result_limit` (Number) Maximum materialized objects from 1 to 10000; defaults to 1000. Zero never enables an unbounded query.
- `scope` (String) base, one_level or subtree; defaults to subtree.

### Read-Only

- `complete` (Boolean) Whether the SDK completed the entire selected search.
- `id` (String) Deterministic query fingerprint; individual objects retain their GUID identities.
- `limit_reached` (Boolean) Whether the configured bound stopped retrieval; it does not prove further matches exist.
- `users` (Attributes List) Usable user observations sorted by GUID. (see [below for nested schema](#nestedatt--users))
