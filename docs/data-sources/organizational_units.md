# activedirectory_organizational_units

Reads organizational units below an explicit search base. Results are bounded, sorted by GUID and report completeness separately.

Configure verified LDAPS using environment-delivered credentials:

```terraform
terraform {
  required_version = ">= 1.14.0"
  required_providers {
    activedirectory = { source = "deploymenttheory/activedirectory" }
  }
}

# Supply AD_HOST, AD_USERNAME, AD_PASSWORD and, for a private CA, AD_CA_CERT_PEM
# through your secret manager or process environment. Hostname/chain checks remain enabled.
provider "activedirectory" {
  auth_method = "simple"
  transport   = "ldaps"
}
```

## Minimal example

```terraform
data "activedirectory_organizational_units" "example" {
  base_dn = "OU=Managed,DC=example,DC=com"
}
```

## Extended example

```terraform
data "activedirectory_organizational_units" "filtered" {
  base_dn      = "OU=Managed,DC=example,DC=com"
  ldap_filter  = "(name=Terraform*)"
  scope        = "one_level"
  page_size    = 256
  result_limit = 1000
}
```

## Observation semantics

Results are sorted by object GUID. `complete` and `limit_reached` distinguish a completed search
from caller-bounded retrieval; a bound does not prove additional matches exist. Failed/partial SDK
reads retain usable observations and report an error. Hidden optional attributes remain null.
Filters are raw LDAP syntax, scoped to organizational units by the SDK; PowerShell expressions are not parsed.
