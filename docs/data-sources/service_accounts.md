# activedirectory_service_accounts (Data Source)

Reads service accounts below an explicit search base. Results are bounded, sorted by GUID and report completeness separately.

```terraform
terraform {
  required_version = ">= 1.14.0"
  required_providers {
    activedirectory = { source = "deploymenttheory/activedirectory" }
  }
}

# Supply AD_HOST, AD_USERNAME, AD_PASSWORD and, for a private CA, AD_CA_CERT_PEM
# through your secret manager or process environment. Hostname/chain checks remain enabled.
provider "activedirectory" {
  auth_method = "simple"
  transport   = "ldaps"
}
```

```terraform
data "activedirectory_service_accounts" "automation" {
  base_dn = "OU=Service Accounts,DC=example,DC=test"
}
```

```terraform
data "activedirectory_service_accounts" "group_managed" {
  base_dn      = "OU=Service Accounts,DC=example,DC=test"
  ldap_filter  = "(objectClass=msDS-GroupManagedServiceAccount)"
  scope        = "one_level"
  page_size    = 100
  result_limit = 500
}
```

The SDK intersects the LDAP filter with its sMSA/gMSA class filter and excludes delegated
managed service accounts. Supply an explicit base DN and finite bounds. Rows sort by GUID;
`complete` describes enumeration and does not establish visibility of every optional attribute.
`limit_reached` means the configured bound stopped retrieval. Usable partial rows are retained
alongside diagnostics. Managed password material and raw security descriptors are never exposed.

## Schema

### Required

- `base_dn` (String) Explicit distinguished name of the search base.

### Optional

- `ldap_filter` (String) Raw LDAP filter intersected with the SDK's service account class filter. PowerShell expressions are not parsed.
- `page_size` (Number) LDAP page size from 1 to 1000; defaults to 256.
- `result_limit` (Number) Maximum materialized objects from 1 to 10000; defaults to 1000. Zero never enables an unbounded query.
- `scope` (String) base, one_level or subtree; defaults to subtree.

### Read-Only

- `complete` (Boolean) Whether the SDK completed the entire selected search.
- `id` (String) Deterministic query fingerprint; individual objects retain their GUID identities.
- `limit_reached` (Boolean) Whether the configured bound stopped retrieval; it does not prove further matches exist.
- `service_accounts` (Attributes List) Usable service account observations sorted by GUID. (see [below for nested schema](#nestedatt--service_accounts))
