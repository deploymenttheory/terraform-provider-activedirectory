# activedirectory_computer (Data Source)

Reads one computer by GUID or DN. Missing or inaccessible objects report a diagnostic; no directory state is managed.

```terraform
terraform {
  required_version = ">= 1.14.0"
  required_providers {
    activedirectory = { source = "deploymenttheory/activedirectory" }
  }
}

# Supply AD_HOST, AD_USERNAME, AD_PASSWORD and, for a private CA, AD_CA_CERT_PEM
# through your secret manager or process environment. Hostname/chain checks remain enabled.
provider "activedirectory" {
  auth_method = "simple"
  transport   = "ldaps"
}
```

```terraform
data "activedirectory_computer" "by_guid" {
  object_guid = "8b48ae8e-aea5-4c45-acef-b319f8db9cf4"
}
```

```terraform
data "activedirectory_computer" "by_dn" {
  dn = "CN=Terraform Automation,OU=Automation,DC=example,DC=test"
}
```

Supply exactly one known `object_guid` or `dn`. Optional hidden/unavailable attributes remain
null; the data source does not fabricate false flags, expose password values or own attributes.
Missing, denied and incomplete observations return diagnostics.
