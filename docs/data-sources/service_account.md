# activedirectory_service_account (Data Source)

Reads one service account by GUID or DN. Missing or inaccessible objects report a diagnostic; no directory state is managed.

```terraform
terraform {
  required_version = ">= 1.14.0"
  required_providers {
    activedirectory = { source = "deploymenttheory/activedirectory" }
  }
}

# Supply AD_HOST, AD_USERNAME, AD_PASSWORD and, for a private CA, AD_CA_CERT_PEM
# through your secret manager or process environment. Hostname/chain checks remain enabled.
provider "activedirectory" {
  auth_method = "simple"
  transport   = "ldaps"
}
```

```terraform
data "activedirectory_service_account" "by_guid" {
  object_guid = "8b48ae8e-aea5-4c45-acef-b319f8db9cf4"
}
```

```terraform
data "activedirectory_service_account" "by_dn" {
  dn = "CN=Terraform Build,OU=Service Accounts,DC=example,DC=test"
}
```

Supply exactly one known `object_guid` or `dn`. The SDK excludes delegated managed service
accounts from this lifecycle projection. Password blobs, raw descriptors and host installation
status are never returned. Hidden reader policy remains null; a returned empty reader set
means no explicit ordinary Read Property allow ACEs, not a guarantee about effective access.
Missing, denied and incomplete observations return diagnostics.
