# activedirectory_computer_service_account (Data Source)

Read one direct computer-account link. Primary and nested association do not satisfy this lookup.

The ordered identity is `computer GUID/service-account GUID`. Names and DNs may
change without changing identity. Endpoints must already exist. These operations
change directory links only: they do not install accounts locally, retrieve or
reset managed passwords, or grant permission to read gMSA passwords. This matches
[Add-ADComputerServiceAccount](https://learn.microsoft.com/en-us/powershell/module/activedirectory/add-adcomputerserviceaccount)
and [Remove-ADComputerServiceAccount](https://learn.microsoft.com/en-us/powershell/module/activedirectory/remove-adcomputerserviceaccount).

Discovery requires an explicit computer GUID and a bound from 1 to 10000
(default 1000). Rows contain complete GUID pairs and sort by service-account
GUID. A truncated or failed observation reports incompleteness. Zero visible
values never prove a complete empty collection; a visibility warning preserves
that distinction. Singular lookup requires a positively observed association.

```terraform
terraform {
  required_version = ">= 1.14.0"
  required_providers {
    activedirectory = { source = "deploymenttheory/activedirectory" }
  }
}

# Supply AD_HOST, AD_USERNAME, AD_PASSWORD and, for a private CA, AD_CA_CERT_PEM
# through your secret manager or process environment. Hostname/chain checks remain enabled.
provider "activedirectory" {
  auth_method = "simple"
  transport   = "ldaps"
}
```

```terraform
data "activedirectory_computer_service_account" "example" {
  computer_guid        = "11111111-1111-4111-8111-111111111111"
  service_account_guid = "22222222-2222-4222-8222-222222222222"
}
```

```terraform
data "activedirectory_computer_service_account" "existing_link" {
  computer_guid        = "11111111-1111-4111-8111-111111111111"
  service_account_guid = "22222222-2222-4222-8222-222222222222"
}

output "direct_link" {
  value = {
    id                 = data.activedirectory_computer_service_account.existing_link.id
    computer_dn        = data.activedirectory_computer_service_account.existing_link.computer_dn
    service_account_dn = data.activedirectory_computer_service_account.existing_link.service_account_dn
  }
}
```
