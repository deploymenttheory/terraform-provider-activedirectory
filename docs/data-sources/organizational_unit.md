# activedirectory_organizational_unit

Reads one organizational unit by GUID or DN. Missing or inaccessible objects report a diagnostic; no directory state is managed.

Configure verified LDAPS using environment-delivered credentials:

```terraform
terraform {
  required_version = ">= 1.14.0"
  required_providers {
    activedirectory = { source = "deploymenttheory/activedirectory" }
  }
}

# Supply AD_HOST, AD_USERNAME, AD_PASSWORD and, for a private CA, AD_CA_CERT_PEM
# through your secret manager or process environment. Hostname/chain checks remain enabled.
provider "activedirectory" {
  auth_method = "simple"
  transport   = "ldaps"
}
```

## Minimal example

```terraform
data "activedirectory_organizational_unit" "example" {
  object_guid = "a3e9767a-200e-43dd-bb1d-e5ab400e5d6f"
}
```

## Extended example

```terraform
data "activedirectory_organizational_unit" "by_dn" {
  dn = "OU=Managed,DC=example,DC=com"
}
```

## Observation semantics

Supply exactly one of `object_guid` or `dn`. The output `id` is always the observed object GUID.
Missing/inaccessible objects and incomplete reads report diagnostics. Hidden optional values remain
null; deletion protection is never inferred from an unavailable security descriptor.
