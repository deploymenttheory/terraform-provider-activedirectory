# activedirectory_groups (Data Source)

Reads groups below an explicit search base. Results are bounded, sorted by GUID and report completeness separately.

```terraform
terraform {
  required_version = ">= 1.14.0"
  required_providers {
    activedirectory = { source = "deploymenttheory/activedirectory" }
  }
}

# Supply AD_HOST, AD_USERNAME, AD_PASSWORD and, for a private CA, AD_CA_CERT_PEM
# through your secret manager or process environment. Hostname/chain checks remain enabled.
provider "activedirectory" {
  auth_method = "simple"
  transport   = "ldaps"
}
```

```terraform
data "activedirectory_groups" "example" {
  base_dn = "OU=Groups,DC=example,DC=test"
}
```

```terraform
data "activedirectory_groups" "application" {
  base_dn      = "OU=Groups,DC=example,DC=test"
  ldap_filter  = "(name=Application*)"
  scope        = "one_level"
  page_size    = 100
  result_limit = 500
}
```

The SDK intersects the supplied raw LDAP filter with its group class filter. Search `scope`
controls depth; each returned object's `scope` describes its group scope. Results sort by GUID;
`complete` and `limit_reached` distinguish exhaustion from bounded materialization. Partial
observations remain alongside errors. Zero does not enable an unbounded search, and PowerShell
filter expressions are not parsed. No membership values are owned or implicitly expanded.

## Schema

### Required

- `base_dn` (String) Explicit distinguished name of the search base.

### Optional

- `ldap_filter` (String) Raw LDAP filter intersected with the SDK's group class filter. PowerShell expressions are not parsed.
- `page_size` (Number) LDAP page size from 1 to 1000; defaults to 256.
- `result_limit` (Number) Maximum materialized objects from 1 to 10000; defaults to 1000. Zero never enables an unbounded query.
- `scope` (String) base, one_level or subtree; defaults to subtree.

### Read-Only

- `complete` (Boolean) Whether the SDK completed the entire selected search.
- `groups` (Attributes List) Usable group observations sorted by GUID. (see [below for nested schema](#nestedatt--groups))
- `id` (String) Deterministic query fingerprint; individual objects retain their GUID identities.
- `limit_reached` (Boolean) Whether the configured bound stopped retrieval; it does not prove further matches exist.
