# activedirectory_group_members (Data Source)

Read bounded direct or explicitly recursive group membership, including primary-group relationships. This data source changes no membership or directory objects.

```terraform
terraform {
  required_version = ">= 1.14.0"
  required_providers {
    activedirectory = { source = "deploymenttheory/activedirectory" }
  }
}

# Supply AD_HOST, AD_USERNAME, AD_PASSWORD and, for a private CA, AD_CA_CERT_PEM
# through your secret manager or process environment. Hostname/chain checks remain enabled.
provider "activedirectory" {
  auth_method = "simple"
  transport   = "ldaps"
}
```

```terraform
data "activedirectory_group_members" "example" {
  group_guid = "11111111-1111-4111-8111-111111111111"
}
```

```terraform
data "activedirectory_group_members" "recursive" {
  group_guid  = "11111111-1111-4111-8111-111111111111"
  recursive   = true
  max_objects = 5000
  max_groups  = 100
  max_ranges  = 100
  max_depth   = 8
  max_bytes   = 8388608

  lifecycle {
    postcondition {
      condition     = self.complete
      error_message = "Membership discovery is incomplete; verify visibility, unresolved references and traversal bounds before using these results as a complete collection."
    }
  }
}
```

Direct mode returns direct and primary-group members. Recursive mode traverses
nested groups and returns leaf principals, preserving primary-group information.
This matches [Get-ADGroupMember](https://learn.microsoft.com/en-us/powershell/module/activedirectory/get-adgroupmember).
This read-only query does not own membership. Individual link resources manage
direct `member` values and do not infer primary or recursive links from these rows.

All five budgets are finite aggregate SDK observation limits, not promises of a
specific result count. Group lookups and repeated path observations consume the
object budget. Raising one limit does not disable the others. Members sort by
source host, source port and GUID; agreeing duplicate paths merge their primary
flags, while conflicting identities retain diagnostics rather than selecting an
arbitrary name. Results are observations, not a transactionally consistent graph.

Empty and hidden member attributes are indistinguishable. If any visited group
returns no direct member values, `visibility_known` and `complete` are false even
when primary members were positively found. Known rows remain available. Bounds,
failed ranges and unresolved references cannot become complete empty membership.
Check completion before using the data as an authoritative collection; the maximal
example deliberately adds a postcondition. The data source owns no objects or links.

The selected provider session is the authenticated directory context. Foreign or
cross-context references that cannot be resolved there remain in `unresolved`
with diagnostics. No connection, referral following or credential forwarding to
an inferred foreign endpoint is performed. An unresolved reference is not a usable
principal GUID or import identity. Peer error text is withheld.

## Schema

### Required

- `group_guid` (String) Existing group object GUID; names and DNs are not query identities.

### Optional

- `max_bytes` (Number) Aggregate observed attribute/name byte budget from 1024 to 67108864; defaults to 8388608.
- `max_depth` (Number) Maximum nested traversal depth from 1 to 32; defaults to 8. Direct mode does not expand nested groups.
- `max_groups` (Number) Maximum traversed groups from 1 to 1000; defaults to 100.
- `max_objects` (Number) Aggregate object observation budget from 1 to 10000, including group/resolution observations; defaults to 1000.
- `max_ranges` (Number) Aggregate member-range read budget from 1 to 1000; defaults to 100.
- `recursive` (Boolean) Traverse nested groups and return leaf principals when true. Defaults to false. Primary-group membership is included, matching Get-ADGroupMember.

### Read-Only

- `complete` (Boolean) Whether requested traversal, ranges and identities completed without known omission or failure. This is not an effective-access or transactional graph guarantee.
- `group_dn` (String) Explicitly observed current group distinguished name.
- `groups_visited` (Number) Number of group traversal observations retained by the SDK.
- `id` (String) Canonical GUID of the group selected by this query.
- `limit_reached` (Boolean) Whether an aggregate traversal budget stopped retrieval; further matches may or may not exist.
- `members` (Attributes List) Usable principals sorted by source host, port and GUID. Duplicate observations merge only when identity and names agree. (see [below for nested schema](#nestedatt--members))
- `unresolved` (Attributes List) Bounded references the SDK could not resolve in the explicitly authenticated context. No foreign connection or credential forwarding is inferred. (see [below for nested schema](#nestedatt--unresolved))
- `visibility_known` (Boolean) Whether every visited group returned at least one direct member value. False preserves the ambiguity shared by an empty and hidden attribute, even when primary members were found.
