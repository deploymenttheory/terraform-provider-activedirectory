# activedirectory_object (Resource)

Manage one AD DS object by GUID with explicit class and raw ownership. Avoid competing typed/generic ownership of the same attributes. Deletion is leaf-only.

```terraform
terraform {
  required_version = ">= 1.14.0"
  required_providers {
    activedirectory = { source = "deploymenttheory/activedirectory" }
  }
}

# Supply AD_HOST, AD_USERNAME, AD_PASSWORD and, for a private CA, AD_CA_CERT_PEM
# through your secret manager or process environment. Hostname/chain checks remain enabled.
provider "activedirectory" {
  auth_method = "simple"
  transport   = "ldaps"
}
```

```terraform
resource "activedirectory_object" "example" {
  name         = "Example Contact"
  parent_dn    = "OU=Contacts,DC=example,DC=test"
  object_class = "contact"
}
```

```terraform
variable "jpeg_photo_path" {
  type        = string
  description = "Path to the contact JPEG photo on the Terraform client."
}
resource "activedirectory_object" "application" {
  name         = "Application Contact"
  parent_dn    = "OU=Contacts,DC=example,DC=test"
  object_class = "contact"
  attributes = {
    description = [base64encode("Application contact")]
    jpegPhoto   = [filebase64(var.jpeg_photo_path)]
  }
  add_values = {
    otherTelephone = [base64encode("+44 20 7946 0123")]
  }
  properties = ["displayName", "telephoneNumber"]
}
```

`name` is a literal naming value; the SDK resolves the selected schema class's naming
attribute. Same-domain rename/move retain the GUID. Selecting a different `object_class` requires
replacement; class-name casing edits retain identity. Never use typed and generic resources to manage the same GUID/attributes.

`attributes` owns complete value sets only for named attributes. `add_values` and
`remove_values` own selected value intent while preserving other values. Only a disjoint
remove/add pair may share an attribute. Omission relinquishes that intent without undoing
values. An empty set is invalid; one empty base64 string is one zero-length value.
`clear_attributes` and `remove_values` require an existing or imported object. The server's
strict LDAP matching/errors remain authoritative, including removing a missing value.

```terraform
# Import this existing contact before applying clear/remove intent.
resource "activedirectory_object" "clear_existing" {
  name             = "Existing Contact"
  parent_dn        = "OU=Contacts,DC=example,DC=test"
  object_class     = "contact"
  remove_values    = { otherTelephone = [base64encode("+44 20 7946 0123")] }
  clear_attributes = ["displayName"]
}
```

Raw values use canonical padded base64, not inferred text/number/DN conversions. Base64
preserves binary values but does not encrypt Terraform state. Configured intent stays
separate from `observed_attributes`, `attribute_status` and incomplete `attribute_ranges`.
An omitted or hidden attribute never proves an independently verified clear.

Accepted schema normalization retains requested intent and actual returned bytes. An
unchanged acknowledged observation does not issue another write; positively observed
drift can schedule reconciliation through `needs_update`. Accepted or uncertain failures
retain identity and a durable recovery checkpoint. No automatic rollback/retry occurs.
Uncertain removal/clear is not reconciled by a later omitted attribute. Failed creation
stays blocked because Terraform can taint it; recover the verified existing GUID explicitly.
Deletion is leaf-only and requires positive same-GUID deletion proof; it never removes a tree.

## Import

Plain GUID and identity imports adopt class/name/location without guessing raw attribute
ownership. Use JSON string import to adopt explicitly selected visible raw values.
Selected owned attributes must be present and complete; unavailable values cause a diagnostic.
`properties` selects extra read-only observations. Import never writes to the directory.

```terraform
import {
  to = activedirectory_object.example
  id = "dc93656c-f745-4926-9bbb-31e7bbecb68b"
}
```

```terraform
import {
  to       = activedirectory_object.example
  identity = { id = "dc93656c-f745-4926-9bbb-31e7bbecb68b" }
}
```

```terraform
# Use this form to adopt specific existing raw values. Configure matching ownership
# on the target resource; import performs reads only and never changes the directory.
import {
  to = activedirectory_object.application
  id = jsonencode({
    id         = "dc93656c-f745-4926-9bbb-31e7bbecb68b"
    attributes = ["description", "jpegPhoto"]
    properties = ["displayName", "telephoneNumber"]
  })
}
```

## Schema

### Required

- `name` (String) Literal object name. The SDK uses the selected class's naming attribute; changes rename the same GUID.
- `object_class` (String) Explicit schema LDAP display name for the instantiated class. Changing it replaces the object.
- `parent_dn` (String) Explicit parent distinguished name. Changes move the same object within its domain.

### Optional

- `add_values` (Map of Set of String) Selected base64 values to add while preserving other values. May initialize values during creation.
- `attributes` (Map of Set of String) Owned attribute values as canonical base64 sets. Empty sets require clear_attributes; omitted attributes remain unowned.
- `clear_attributes` (Set of String) Explicit attributes to clear on an existing object. Omission never clears an attribute; unavailable readback alone never proves a clear.
- `properties` (Set of String) Additional raw attributes to observe without owning their values.
- `remove_values` (Map of Set of String) Selected base64 values to remove on an existing object, preserving other values. The server enforces LDAP matching and strict errors.

### Read-Only

- `attribute_ranges` (Map of Set of String) Incomplete returned ranges, kept separate from complete attributes.
- `attribute_status` (Map of String) present, absent, unloaded or partial for each selected raw attribute.
- `distinguished_name` (String) Current directory-observed distinguished name.
- `id` (String) Stable nonzero object GUID used for lifecycle and import.
- `needs_update` (Boolean) A complete returned value set contradicted owned intent. Terraform schedules reconciliation; false does not prove hidden or absent values are unset.
- `object_classes` (List of String) Ordered directory-observed class hierarchy.
- `observed_attributes` (Map of Set of String) Raw selected attribute values as base64 sets. Unavailable or partial values remain null, independently of configured intent.
- `recovery_dn` (String) Recovery locator if creation acceptance precedes usable GUID observation. Never an identity substitute.
