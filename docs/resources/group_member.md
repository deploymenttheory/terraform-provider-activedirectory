# activedirectory_group_member (Resource)

Manage one direct group/member link. Existing links are adopted; deletion removes only this link. Other members and both directory objects are preserved. Primary and nested membership are not direct links.

```terraform
terraform {
  required_version = ">= 1.14.0"
  required_providers {
    activedirectory = { source = "deploymenttheory/activedirectory" }
  }
}

# Supply AD_HOST, AD_USERNAME, AD_PASSWORD and, for a private CA, AD_CA_CERT_PEM
# through your secret manager or process environment. Hostname/chain checks remain enabled.
provider "activedirectory" {
  auth_method = "simple"
  transport   = "ldaps"
}
```

```terraform
resource "activedirectory_group_member" "example" {
  group_guid  = "11111111-1111-4111-8111-111111111111"
  member_guid = "22222222-2222-4222-8222-222222222222"
}
```

```terraform
# Each instance owns one link. Members omitted from this set remain unmanaged.
resource "activedirectory_group_member" "application_readers" {
  for_each = toset([
    "22222222-2222-4222-8222-222222222222",
    "33333333-3333-4333-8333-333333333333",
  ])
  group_guid  = "11111111-1111-4111-8111-111111111111"
  member_guid = each.value
}
```

GUIDs identify directory objects; names and DNs may change without changing the
ordered relationship identity. Primary-group and nested/effective membership are
excluded. Foreign security principal resolution is not performed.

Creation adopts an existing direct link or adds that one link. Deletion removes
only the owned link and leaves both objects and other members intact. Changing
either endpoint replaces the owned link. Do not manage the same pair in multiple
Terraform states or through a competing member collection.

New additions request persistent links. Existing link expiry is not managed or
silently converted; there is no TTL input. Unresolved submitted effects retain
nonsecret recovery intent and block another mutation until fresh directory
observations reconcile the exact pair. No automatic write retry or rollback occurs.
