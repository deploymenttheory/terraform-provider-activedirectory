# activedirectory_group (Resource)

Manage one AD DS group by GUID. Category/scope changes preserve unrelated flags. Membership belongs to separate edge resources; deletion removes the group only.

## Provider configuration

```terraform
terraform {
  required_version = ">= 1.14.0"
  required_providers {
    activedirectory = { source = "deploymenttheory/activedirectory" }
  }
}

# Supply AD_HOST, AD_USERNAME, AD_PASSWORD and, for a private CA, AD_CA_CERT_PEM
# through your secret manager or process environment. Hostname/chain checks remain enabled.
provider "activedirectory" {
  auth_method = "simple"
  transport   = "ldaps"
}
```

## Minimal group

```terraform
resource "activedirectory_group" "example" {
  name             = "Application Readers"
  sam_account_name = "app-readers"
  parent_dn        = "OU=Groups,DC=example,DC=test"
  category         = "security"
  scope            = "global"
}
```

## Explicit properties

```terraform
resource "activedirectory_group" "maximal" {
  name             = "Application Operators"
  sam_account_name = "app-operators"
  parent_dn        = "OU=Groups,DC=example,DC=test"
  category         = "security"
  scope            = "domain_local"
  description      = "Operators for application access"
  display_name     = "Application Operators"
  home_page        = "https://applications.example.test/"
  managed_by_dn    = "CN=Application Owner,OU=People,DC=example,DC=test"
}
```

The object GUID remains stable across supported same-domain rename and move operations.
Category and scope are semantic patches: unrelated `groupType` bits remain owned by the
directory. The SDK submits one guarded atomic modification and rejects a concurrently changed
old value. The server enforces scope/category conversion and membership constraints; the
provider does not perform an implicit intermediate conversion, retry or rollback.

Membership belongs to separate edge resources. This resource never replaces a member collection.
Omitted optional properties retain observed values. Hidden, ranged or unavailable attributes
do not imply empty values; their prior managed values are retained with diagnostics.

## Explicit property clearing

```terraform
# After importing the existing group, explicitly clear only the selected property.
resource "activedirectory_group" "adopted" {
  name             = "Application Readers"
  sam_account_name = "app-readers"
  parent_dn        = "OU=Groups,DC=example,DC=test"
  category         = "security"
  scope            = "global"
  clear_properties = ["description"]
}
```

Clears accept `description`, `displayName`, `wWWHomePage` and `managedBy` only. Removing a
configured optional property leaves it unmanaged. An acknowledged clear is distinct from an
uncertain operation, whose effect cannot be proved from omission alone.

## Schema

### Required

- `category` (String) security or distribution. Updates use the SDK's typed patch and preserve unrelated groupType bits.
- `name` (String) Literal group name. Changes rename the same object GUID.
- `parent_dn` (String) Explicit parent distinguished name. Changes move the same group within its domain.
- `sam_account_name` (String) Explicit sAMAccountName. No account name or container is guessed.
- `scope` (String) global, domain_local or universal. The directory decides whether a requested scope conversion is permitted.

### Optional

- `clear_properties` (Set of String) Explicit description, displayName, wWWHomePage or managedBy attributes to clear on an existing group. Omission retains observed values.
- `description` (String) Typed description property. Omit to retain the observed value; clear_properties requests an explicit clear.
- `display_name` (String) Typed displayName property. Omit to retain the observed value; clear_properties requests an explicit clear.
- `home_page` (String) Typed wWWHomePage property. Omit to retain the observed value; clear_properties requests an explicit clear.
- `managed_by_dn` (String) Typed managedBy property. Omit to retain the observed value; clear_properties requests an explicit clear.

### Read-Only

- `distinguished_name` (String) Current directory-observed distinguished name.
- `id` (String) Stable group object GUID used for import and lifecycle identity.
- `recovery_dn` (String) Recovery locator when creation acceptance precedes GUID observation.
- `sid` (String) Directory-assigned security identifier when visible.

### Identity Schema

#### Required

- `id` (String) Stable nonzero group object GUID.

Accepted phases and the known GUID are retained if later work fails. An unresolved operation
blocks further writes until observation proves its effect or an operator independently verifies
the object and performs explicit GUID recovery. A failed creation can remain tainted in
Terraform; it is never automatically replaced while its creation checkpoint is unresolved.
DN-only candidates are not adopted as identity.

Deletion removes only the selected leaf group. It never deletes member objects or a subtree.
Denied, nonempty, protected or unverified deletion retains state and requires reconciliation.
