# activedirectory_organizational_unit

Manages one Active Directory organizational unit using stable GUID identity. Deletion is always nonrecursive.

Configure verified LDAPS using environment-delivered credentials:

```terraform
terraform {
  required_version = ">= 1.14.0"
  required_providers {
    activedirectory = { source = "deploymenttheory/activedirectory" }
  }
}

# Supply AD_HOST, AD_USERNAME, AD_PASSWORD and, for a private CA, AD_CA_CERT_PEM
# through your secret manager or process environment. Hostname/chain checks remain enabled.
provider "activedirectory" {
  auth_method = "simple"
  transport   = "ldaps"
}
```

## Minimal example

```terraform
resource "activedirectory_organizational_unit" "example" {
  name      = "Terraform Example"
  parent_dn = "OU=Managed,DC=example,DC=com"
}
```

## Extended example

```terraform
resource "activedirectory_organizational_unit" "full" {
  name                               = "Terraform Full Example"
  parent_dn                          = "OU=Managed,DC=example,DC=com"
  description                        = "Managed organizational unit"
  display_name                       = "Terraform Full Example"
  city                               = "Cardiff"
  country                            = "GB"
  state                              = "Wales"
  street_address                     = "1 Example Street"
  postal_code                        = "CF10 1AA"
  managed_by                         = "CN=Directory Manager,OU=People,DC=example,DC=com"
  protected_from_accidental_deletion = true
}
```

## Ownership, protection and recovery

Omitted optional properties retain their observed directory values. Clear an existing attribute
explicitly with `clear_properties`, using LDAP names: description, displayName, l, c, st,
street, postalCode or managedBy. A property cannot be configured and cleared together.

```terraform
# Update an existing/imported OU; omit description while explicitly requesting its clear.
resource "activedirectory_organizational_unit" "example" {
  name             = "Terraform Example"
  parent_dn        = "OU=Managed,DC=example,DC=com"
  clear_properties = ["description"]
}
```

Protection defaults to true. Apply `protected_from_accidental_deletion = false` explicitly
before destroying or moving a protected OU. Destroy never disables protection or deletes
children recursively. Same-domain rename/move retain the object GUID; cross-domain moves are excluded.

A failed write may already have changed the directory. Known GUIDs and accepted effects are
retained; a GUID-less creation keeps `recovery_dn` for reconciliation. Read hidden/partial
properties as unavailable, rather than proof of an empty value. Reconcile before another write;
the provider never replays a failed mutation or rolls it back automatically.

Unresolved intent is retained in provider private state across failed applies. A complete read
must prove the requested effects before further writes. An uncertain clear cannot be proved by
an omitted attribute. A creation without an observed GUID never adopts a DN-only candidate.
If readback cannot settle the operation, verify the object independently and perform explicit
state/import recovery using its confirmed GUID; preserve the existing state before recovery.
Terraform taints failed creations. Even when their GUID is retained, the provider blocks
automatic replacement until explicit recovery adopts the verified existing object.

## Import

Import by immutable GUID, including an object that has been renamed or moved:

```terraform
import {
  to = activedirectory_organizational_unit.example
  id = "a3e9767a-200e-43dd-bb1d-e5ab400e5d6f"
}
```

Or import by the same identity object emitted by list discovery:

```terraform
import {
  to = activedirectory_organizational_unit.full
  identity = {
    id = "b3e9767a-200e-43dd-bb1d-e5ab400e5d6f"
  }
}
```
