# SDK operation-to-Terraform matrix

Every source operation appears once. Included means planned and gated, not implemented or qualified. The [type catalog](terraform-types.md) gives exact type names and layout; ticket bodies carry verification and dependencies. All included operations require per-feature version applicability and Linux/Windows lab evidence. Six host-local/cloning operations are excluded.
