## Per-type documentation paths

For every catalog row, use `examples/<category>/<full Terraform type>/` and `templates/<category>/<suffix>.md.tmpl`, with generated documentation under `docs/<category>/`. Categories are `resources`, `data-sources`, `list-resources`, and `actions`. Resource examples include import; list examples demonstrate discovery/import; actions include safe invocation and recovery. Feature-local unit/acceptance fixtures remain separate from public examples.
